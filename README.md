# walmartprodct — DEMO / TEST crypto dashboard

This is a self-contained demo application. It does NOT mine ETH, custody crypto, process real deposits, or send real withdrawals.

## Requirements
- Node.js 18+ recommended

## Run
```bash
npm install
npm start
```
Open http://localhost:3000

## Demo admin
Email: admin@walmartprodct.demo
Password: DemoAdmin123!

Change the password and SESSION_SECRET before any deployment.

## Included
- Customer registration/login
- Mobile-first dark fintech UI
- Demo USDT/ETH balances
- Simulated deposits and withdrawals
- Pending withdrawal workflow
- Admin overview, users, balances, deposits, withdrawals
- Demo balance adjustments with audit logging
- Maintenance mode and settings
- SQLite database
- Server-side sessions and bcrypt password hashing
- No real blockchain integration

For production use, have security, legal, KYC/AML, custody, and compliance requirements reviewed before connecting any real funds.
